# Claude plugins

Claude Code plugins by Studio Miyanko, published as the marketplace `studio-miyanko`.

| Plugin | Does |
|---|---|
| [wow-addon-dev](plugins/wow-addon-dev) | WoW addon and WeakAura development, checked against Blizzard's UI source for each game flavor |

wow-forever-search was retired on 2026-10-16. For WoW Forever lookups, add the MCP servers [wowhead-mcp](https://github.com/studio-miyanko/wowhead-mcp) and [wow-armory-mcp](https://github.com/studio-miyanko/wow-armory-mcp) directly.

## Install

```
/plugin marketplace add studio-miyanko/claude-plugins
/plugin install wow-addon-dev@studio-miyanko
```

Swap in any plugin name from the table.
